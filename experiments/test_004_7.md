## 목적

기존 `TEST_004_6`의 전체 예측은 유지하면서 혼동이 잦은 `KIRC↔KIPAN`,
`LGG↔GBMLGG` 구간에만 팀 파이프라인을 전문가로 사용한다. 전역 앙상블을 하지 않아
이미 잘 맞히는 암종의 예측 변화를 제한한다.

- 기반 모델: `TEST_004_6` / `pipeline_jsj_v8.py`

- 보조 전처리: `pipeline_em_v16.py` 40% + `pipeline_em_v24.py` 60%
- 보조 예측 모델: XGBoost E4, Stratified 5-Fold, seed 42
- KIRC/KIPAN 전문가 가중치: 0.35
- LGG/GBMLGG 전문가 가중치: 0.30
- 외부 데이터 사용: 없음
- test 데이터 학습 사용: 없음

## 재현 방법

저장소 루트의 `data/raw/`에 `train.csv`, `test.csv`,
`sample_submission.csv`를 둔다.

설정 연결만 빠르게 확인:

```bash
python -m src.reproduce_test_004_7 --config configs/test_004_7.yaml --check-only
```

전체 재현 및 CSV 생성:

```bash
python -m src.reproduce_test_004_7 --config configs/test_004_7.yaml
```

처음 실행하면 `TEST_004_6` 기반 OOF를 먼저 만든 뒤 em_v16·em_v24를 각각 5-Fold로
학습한다. 이후 실행에서는 `data/processed`의 검증된 캐시를 사용한다.

생성 파일:

```text
data/processed/EM_SJ_pipeComb_v1.csv
data/processed/TEST_004_7_metrics.json
```
