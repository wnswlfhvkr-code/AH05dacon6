# em_v17 토큰·consequence·hotspot·multi-hit 실험 결과

## 1. 실험 목적과 처리 흐름

`train.csv`의 유전자별 셀 문자열을 하나의 범주로 인코딩하지 않고, 실제 변이 토큰 단위로 분해하여 유전자별 변이 양과 반복 변이 정보를 모델에 제공했다.

```text
셀 문자열 분리
→ 표본·유전자 내 중복 토큰 제거
→ 변이별 consequence 판정
→ 유전자별 mutation_count, hotspot, multi-hit 생성
→ 학습 fold 내부 빈도 선택 및 고상관 중복 제거
```

- `mutation_count`: 한 표본의 해당 유전자에서 관측된 고유 변이 토큰 수
- `multi_hit`: 한 유전자에 서로 다른 변이 토큰이 2개 이상이면 1
- `consequence_max`: synonymous=1, missense=2, in-frame=3, truncating=4 중 최대값
- `hotspot`: 학습 fold에서 5개 이상 표본에 반복된 정확한 `(gene, mutation token)`의 존재 여부
- 모든 빈도와 hotspot 선택은 각 학습 fold에서만 수행해 검증 데이터 누수를 방지

## 2. 일반화·차원 제어 설정

| 설정 | 값 | 이유 |
| --- | ---: | --- |
| 최소 유전자 변이 표본 수 | 5 | 극희소 유전자 노이즈 제한 |
| 최대 유전자 수 | 3,000 | 유전자당 3개 파생 피처에 따른 차원 폭증 제한 |
| 최소 hotspot 표본 수 | 5 | 단일·우연 변이를 hotspot으로 학습하지 않도록 제한 |
| 최대 hotspot 수 | 384 | 반복 변이 피처의 상한 고정 |
| 고상관 기준 | `|Pearson r| >= 0.90` | 동일 유전자에서 파생된 중복 표현 제거 |

상관 제거 우선순위는 hotspot → mutation_count → multi-hit → consequence_max다. 서로 다른 유전자의 공발생 자체는 생물학적 신호일 수 있으므로, 상관 제거는 동일 유전자 파생 피처 및 표본 요약 피처 안에서만 수행했다.

## 3. 공통 학습·평가 조건

- 보조 평가: seed 42의 80% 학습/20% 검증

## 6. 최종 전체 학습 피처 구성

후보 피처 9,390개에서 고상관 1,543개와 전체 학습에서 상수인 249개를 제거해 최종 7,598개를 사용했다.

| 피처 유형 | 생성 수 | 고상관 제거 | 상수 제거 | 최종 유지 |
| --- | ---: | ---: | ---: | ---: |
| 유전자 mutation_count | 3,000 | 0 | 0 | 3,000 |
| 유전자 multi-hit | 3,000 | 1 | 249 | 2,750 |
| 유전자 consequence_max | 3,000 | 1,539 | 0 | 1,461 |
| recurrent hotspot | 384 | 1 | 0 | 383 |
| 표본 consequence 요약 | 6 | 2 | 0 | 4 |
| 합계 | 9,390 | 1,543 | 249 | **7,598** |

검사한 동일 유전자 파생 피처의 제거 전 최대 절대 상관은 0.992502였다. consequence_max가 mutation_count와 중복되는 유전자가 많아 가장 많이 제거됐으며, multi-hit 상수 열은 전체 학습 표본에서 서로 다른 변이가 2개 이상 관측되지 않은 유전자다.

## 8. 기존 em_v16과 비교

| 파이프라인 | 모델 조건 | OOF F1 | fold 표준편차 | 과적합 격차 |

| `em_v16` E1 | 동일 100-tree 저복잡도 모델 | **0.393177** | 0.008966 | **0.110879** |
| `em_v16` E4 | 500-tree·낮은 학습률 | **0.394757** | **0.002167** | 0.127743 |

동일 모델인 em_v16 E1보다 em_v17의 OOF는 0.032261 낮고 과적합 격차는 0.021659 높다. 토큰 기반 피처는 해석 가능성과 fold 안정성은 확보했지만, 현재 설정에서는 class-aware OOF signature의 분류력을 대체하지 못한다.

## 10. 결론

- 요청한 토큰 분리 → 중복 제거 → consequence → 유전자별 count/hotspot/multi-hit 처리를 구현하고 실제 학습했다.
- 신규 em_v17은 OOF 0.360916, fold 표준편차 0.005490으로 분할 안정성은 좋다.
- 과적합 격차 0.132538로 기준을 넘으므로 최종 단독 모델로 em_v16을 대체하지 않는다.
- 다음 개선은 mutation_count와 consequence_max를 모두 확장하기보다, em_v16에 recurrent hotspot과 multi-hit만 추가하는 ablation이 적절하다.
