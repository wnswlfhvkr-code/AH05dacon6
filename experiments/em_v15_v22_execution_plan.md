# EM v15~v22 실행 계획

> 과거 실험 기록: `em_v17~em_v22` 소스는 성능 비교 후 제거되었으며 현재
> 사용 가능한 신규 연구 파이프라인은 `em_v15`, `em_v16`이다.

각 버전은 이전 개선 단계를 누적하지만 다른 버전 클래스를 상속하지 않고
`PreprocessingPipeline`을 직접 상속한다.

| 버전 | 추가 단계 | 평가·학습 동작 |
| --- | --- | --- |
| em_v15 | Stratified 5-fold OOF | OOF 전체 F1, fold 평균·표준편차 출력 |
| em_v16 | inner-fold OOF signature | 학습 표본의 자기 정답 영향을 제거한 signature 생성 |
| em_v17 | signature 일치율 | `match_count / mutation_burden` 추가 |
| em_v18 | 기능 결과 비율 중심 | consequence 절대 개수를 빼고 비율 4개 사용 |
| em_v19 | 안정 hotspot | 5개 fold 중 기본 4개 이상에서 선택되는 hotspot만 사용 |
| em_v20 | XGBoost 규제 | YAML의 depth, child weight, 행·열 표본추출, L1·L2 사용 |
| em_v21 | 클래스 가중치 | 클래스 빈도의 역제곱근 표본 가중치 적용 |
| em_v22 | OOF confusion 보정 | 교차 적합 OOF F1이 개선될 때만 클래스 확률 보정 적용 |

## 실행 방법

실험 YAML의 `preprocessing.name`을 원하는 버전으로 지정한 뒤 실행한다.

```bash
python -m src.train --config configs/test_005.yaml
```

`em_v16` 이후 사용할 수 있는 기본 파라미터는 다음과 같다.

XGBoost 규제값은 파이프라인에 중복 저장하지 않고 실험 YAML의 `model`만
사용한다.

```yaml
preprocessing:
  name: em_v22
  min_mutation_count: 5
  top_genes_per_class: 20
  smoothing: 0.5
  max_log2_odds: 8.0
  shrinkage: 10.0
  min_hotspot_count: 5
  max_hotspots: 384
  inner_signature_folds: 5
  stable_hotspot_folds: 5
  min_hotspot_folds: 4
```

## 공통 결과 지표

- `final_macro_f1`: em_v15 이후에는 전체 OOF 예측 F1, 이전 버전은 20% 검증 F1
- `train_macro_f1_80pct`: 동일한 80% 학습 데이터에 대한 학습 점수
- `validation_macro_f1`: 고정된 20% 검증 데이터 점수
- `overfit_gap`: 80% 학습 점수에서 20% 검증 점수를 뺀 값
- `is_overfitting`: 기본 임계값 0.1보다 격차가 큰지 여부
- `oof_evaluation.fold_mean_macro_f1`: 5개 fold 점수의 평균
- `oof_evaluation.fold_std_macro_f1`: 5개 fold 점수의 표준편차

## 결과 해석

- 현재 설정에서 가장 높은 전체 OOF F1은 `em_v16`의 `0.401952`이다.
- `em_v16`은 20% 검증 F1도 `0.420542`로 가장 높고 과적합 격차도
  `0.178855`로 가장 작다.
- `em_v17`의 signature 일치율은 `em_v16`보다 OOF F1을 `0.003953`
  낮췄다.
- `em_v18`의 consequence 비율 전용 구성과 `em_v19`의 안정 hotspot은
  현재 기준에서 추가 성능 하락을 만들었다.
- `em_v19`와 `em_v20`은 모델 규제를 공통 YAML에서 사용하므로 현재 실행
  조건이 같아 결과도 동일하다.
- `em_v21`의 클래스 가중치는 `em_v19/20`보다 OOF F1을 높였지만 학습–검증
  격차도 함께 증가시켰다.
- `em_v22`의 confusion 보정은 OOF F1을 `0.008065` 낮춰 적용되지 않았다.
