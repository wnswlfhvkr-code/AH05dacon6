## 핵심 인사이트

### 1. RAW exact-cell OrdinalEncoder는 일관되게 불리했습니다

동일 단계의 RAW 포함/제외 네 쌍에서 no-raw가 모두 개선됐습니다.

| 비교 | no-raw 개선 |
| --- | ---: |
| F0 | +0.028213 |
| F3 | +0.019146 |
| F4 support 10 | +0.016793 |
| F5 K25 | +0.017923 |
| 평균 | **+0.020519** |

RAW 문자열에 부여된 임의의 순서가 XGBoost 분기에 불필요한 구조를 만들었을 가능성과 일치합니다. 이후 전처리 기준은 no-raw가 타당합니다.

### 2. 환자 단위 변이 부담 F1이 가장 강한 저비용 피처였습니다

F0에서 F1을 추가할 때 피처는 26개만 늘었지만 Macro F1은 `+0.060522` 상승했습니다. 암종 분류에는 개별 유전자뿐 아니라 환자의 전체 변이량과 변이 구성비가 강하게 작용합니다.

### 3. 변이 유형 F2는 유효하지만 위치 F3는 선택적으로 사용해야 합니다

F2는 F1 대비 `+0.019050` 개선됐습니다. 반면 위치 구간만 추가한 F3-position은 `-0.004806` 하락했습니다. 위치 정보는 단독으로는 희소성과 잡음이 크며, 아미노산 치환 방향까지 포함했을 때에만 F2 대비 순개선 `+0.009617`이 생겼습니다.

### 4. F4는 큰 점수 상승보다 안정적인 세부 보완과 피처 정리에 의미가 있습니다

F3 no-raw에서 최종 F4로의 상승은 `+0.003511`로 작지만 양수입니다. 특히 `f4_s5_no_raw`와 `f4_no_raw_hot5`는 같은 점수와 사실상 같은 Test 예측을 만들면서, 후자가 피처를 27,434개 줄였습니다. 최종 F4 recipe는 성능보다도 복잡도 절감과 재현성 측면에서 우수합니다.

### 5. F5의 0.415031은 유망하지만 현재 증거로는 운영 승격값이 아닙니다

F5 missmask는 F4보다 104개 피처만 추가해 holdout에서 `+0.016788` 개선했습니다. 그러나 optimizer에서 같은 holdout을 반복 탐색한 target-aware 결과이며, Git 안에는 이 F5 후보의 독립 다중 seed·paired bootstrap 결과가 없습니다. 따라서 이 값은 후보 발굴 근거이지 일반화가 확인된 최종 점수로 해석하면 안 됩니다.

또한 optimizer의 `f5_no_raw` 최고점과 missmask 실행 점수가 모두 `0.415031`이므로, 현재 holdout에서는 결측 마스크 자체의 추가 이득이 관찰되지 않았습니다. missmask의 의미는 점수 상승보다 결측을 WT와 분리했다는 데이터 의미 보존에 있습니다.

F5 selective는 희소 클래스 5개만 남기면 `0.397690`으로 F4와 거의 같았지만, 10개를 남기면 `0.408814`까지 회복했습니다. 여기에 F7 4개를 추가한 F8은 `0.408919`로 N=10보다 `+0.000105` 높았습니다. 개선 폭은 작지만 방향은 양수이므로 점수 부족으로 탈락시키지 않습니다. 현재 F8은 N=10과의 반복 paired 검증으로 안정성을 비교하기 전까지 보류하며, 안정성이 비슷하고 평균 Macro F1 변화가 양수로 유지되면 승격합니다.

### 6. F6는 압축 효율은 높지만 암종 특이 유전자 신호를 지나치게 잃었습니다

F6는 F4 피처의 99.72%를 제거해 154개로 줄였지만 점수는 `-0.051182` 하락했습니다. F1 점수 `0.346919`와 F6 점수 `0.347061`이 거의 같다는 점에서, SVD 압축이 변이 부담 수준의 정보는 보존했지만 F2~F4의 암종 특이적인 희소 신호는 충분히 보존하지 못한 것으로 해석됩니다.

### 7. F7은 승격되지만 분포 안정성 위험이 있습니다

F7은 F4에 4개 피처만 더해 단일 holdout에서 `+0.000946`, 3-seed 평균에서 `+0.002347` 개선했습니다. 실제 리더보드에서도 F4보다 `+0.0155273170` 높은 `0.3034169097`을 기록했습니다. 다중-seed와 리더보드가 같은 개선 방향을 보여 F7을 최종 후보로 유지합니다. 다만 bootstrap CI가 0을 포함하고 PSI가 매우 높아 분포 안정성 위험은 진단 경고로 남깁니다.

## 승격 판정 규칙

- 같은 분할·seed·Fold에서 기준안과 후보를 paired 비교합니다.
- 후보 안정성이 기준안과 비슷하고 평균 Macro F1 변화가 `0보다 크면` 개선 폭이 작아도 승격합니다.
- seed별 방향 반전, Fold 변동, 클래스별 급락, 분포 drift가 기준안보다 명백히 나빠지면 보류합니다.
- `+0.003` 같은 고정 최소 개선 폭은 사용하지 않습니다.
- bootstrap CI와 PSI는 안정성 진단에 함께 사용하되, 한 항목만으로 자동 탈락시키지 않습니다.

로컬 F4 holdout `0.398243`과 리더보드 `0.2878895927`의 차이는 단일 분할 점수를 제출 의사결정에 직접 사용하면 위험하다는 가장 강한 근거입니다. F7은 다중 Fold 개선과 리더보드 `0.3034169097`이 같은 방향이므로 현재 최종 제출 후보로 보는 것이 타당합니다.
