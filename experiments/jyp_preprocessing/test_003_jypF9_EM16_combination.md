## 4. 암종별 영향

V16 w60은 F9 대비 평균 클래스 F1이 26개 중 19개에서 개선되고 7개에서 하락했다.

- 큰 개선: DLBC `+0.197490`, ACC `+0.080464`, BLCA `+0.065572`, HNSC `+0.033549`
- 큰 하락: TGCT `-0.045506`, PAAD `-0.022030`, SKCM `-0.021626`
- KIRC `-0.001199`로 거의 동일

희소 클래스 DLBC의 개선 폭이 크므로 Macro F1 상승의 일부는 희소 클래스 영향이다. 그러나 bootstrap CI와 3개 seed가 모두 개선되어 한 분할만의 우연으로 보지는 않는다.
