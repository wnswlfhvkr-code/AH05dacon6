개인보드는 리더보드 점수가 아니라 5-Fold OOF Macro F1입니다.

코드 내부의 `MultiPair`는 혼동 암종 쌍별 Logistic Regression 전문가를,
`FullMeta`는 Logistic Regression Stacking을 식별하는 프로젝트 내부 명칭입니다.

## 차이와 채택 판단

- v2는 v1보다 OOF가 `+0.008573` 높았습니다.
- Public은 v1이 v2보다 `+0.012502` 높았습니다.
- v2는 더 많은 규칙을 허용해 학습 OOF 패턴에 민감해졌고, 테스트 분포로의 전이가 약해졌습니다.
- 따라서 두 결과 중 재사용 기준 모델은 **TEST_004_8 / VoteSelect v1**입니다.

## GitHub 재현

저장소 루트에 대회 원본 파일을 아래 위치에 둡니다.

```text
data/raw/train.csv
data/raw/test.csv
data/raw/sample_submission.csv
```

환경 설치 후 각각 실행합니다.

```bash
pip install -r requirements.txt
git lfs pull

python -m src.reproduce_test_004_vote_select --config configs/test_004_8.yaml
python -m src.reproduce_test_004_vote_select --config configs/test_004_9.yaml
```

생성 결과:

```text
data/processed/JSJ_VoteSelect_v1_reproduced.csv
data/processed/TEST_004_8_metrics.json
data/processed/JSJ_VoteSelect_v2_reproduced.csv
data/processed/TEST_004_9_metrics.json
```

실행기는 설정·모델 사양·파이프라인 연결, 원본 ID 순서, 확률 번들 SHA-256,
최종 CSV SHA-256을 모두 검증합니다. `exact_historical_reproduction: true`가 출력되면
어제 제출한 파일과 바이트 단위로 동일합니다.

## 규정 확인

- 외부 데이터 미사용
- 테스트 정답 미사용
- OOF 규칙은 각 검증 fold를 제외한 학습 fold에서만 생성
- 테스트 데이터는 학습된 전체 OOF 패턴 규칙의 최종 예측 적용에만 사용
