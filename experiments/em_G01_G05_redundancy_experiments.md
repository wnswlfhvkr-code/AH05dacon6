# EMV46 저빈도·중복·고상관 제거 실험 설계

## 공통 처리 순서

모든 실험은 EMV46을 한 번만 생성한 뒤 다음 순서를 동일하게 적용한다.

```text
EMV46
→ 상수 피처 제거
→ 최소 활성 빈도 필터
→ 완전히 동일한 피처 제거
→ |Pearson 상관계수| ≥ 0.90 후보 탐색
→ 실험별 우선 기준으로 대표 피처 유지
```

최소 활성 빈도 후보는 `1, 2, 3, 5, 10, 20`이며 각 outer 학습 fold
안에서 3-fold Macro F1을 비교한다. 평균 F1이 같으면 fold 표준편차가 낮은
후보를 선택한다. 선택된 열과 모든 통계는 validation/test가 아니라 학습
부분으로만 결정한다.

완전 중복 피처는 값이 실제로 같은지 재검증한 뒤 하나만 유지한다. 고상관
탐색은 계산량과 과적합을 제한하기 위해 클래스 연관성·fold 안정성이 높은
최대 3,000개 후보를 block 단위로 계산한다. 동일 상관 그룹에서 단순히 먼저
발견한 피처를 남기지 않는다.

## 실험별 대표 피처 기준

| 실험 | 1순위 기준 | 목적 | 주의점 |
| --- | --- | --- | --- |
| `em_G01` | 클래스 연관성 | Macro F1 신호 보존 | 레이블 사용 통계는 fold-train에서만 계산 |
| `em_G02` | 5-fold 선택 안정성 | fold 변화에 강한 피처 유지 | 평균 성능보다 분산 감소에 유리할 수 있음 |
| `em_G03` | 활성 변이 빈도 | 희귀 신호의 우연한 적합 억제 | 소수 암종 특이 변이를 과도하게 지울 수 있음 |
| `em_G04` | 해석 가능성 | 유전자·hotspot·consequence 계보 우선 | 외부 임상 주석 없이 제공 데이터의 피처명만 사용 |
| `em_G05` | 원본 결측 편향 | 측정 누락과 연관된 피처 의존 감소 | 결측률 동률이면 클래스 연관성으로 결정 |

각 1순위 기준이 같을 때는 클래스 연관성, fold 안정성, 활성 빈도, 해석
가능성, 낮은 결측률을 순차 tie-break로 사용한다. 따라서 정보량이 전혀 없는
피처를 해석 가능성만으로 유지하지 않는다.

## 공통 모델 규제

피처 선택 기준만 공정하게 비교하도록 다섯 실험의 XGBoost 설정을 동일하게
고정한다.

- trees 450, learning rate 0.025, depth 3
- min child weight 10
- row sample 0.70, column sample 0.45
- alpha 2, lambda 20
- validation 조기 종료 30 rounds

이는 기존 EMV46의 trees 500, learning rate 0.03, min child weight 7보다
보수적인 설정으로, 고차원 파생 피처의 Train F1 상승과 과적합 격차를
완화하기 위한 시작점이다.

## 선택 원칙

1. OOF Macro F1을 최우선으로 비교한다.
2. F1이 비슷하면 Train-Validation 격차와 fold 표준편차가 작은 실험을 고른다.
3. test 데이터로 빈도·상관계수·결측률·임계값을 조정하지 않는다.
4. GBMLGG, KIPAN, STES는 원본 SUBCLASS 그대로 유지한다.
5. 외부 임상 정보, 유전자 주석 또는 pathway 데이터는 사용하지 않는다.

현재는 파이프라인·설정·평가 절차만 설계했으며 학습, 평가, submission 생성,
결과 분석은 수행하지 않았다.
