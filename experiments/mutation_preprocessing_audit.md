# 변이 문자열 전처리 감사 결과

## 목적

피처 엔지니어링에 앞서 원본 변이 문자열의 실제 표기 상태를 확인하고,
정보 손실 없이 사용할 수 있는 전처리 규칙을 확정했습니다. 이 단계에서는
라벨 기반 marker 선정이나 예측 모델 학습을 수행하지 않았습니다.

train과 test는 샘플당 변이 이벤트 수와 다중 변이 셀 비율에서 차이가

후보 중 하나이므로, 이후 반복 CV와 피처 검증에서 반드시 확인해야 합니다.

## 발견한 핵심 문제

한 유전자 셀에 다음처럼 여러 변이가 공백으로 나열돼 있습니다.

```text
L26V L24V
V600E V512E V603E V640E
E746_A750del E693_A697del
```

기존 방식처럼 공백을 제거하면 서로 다른 변이가 하나의 문자열로
합쳐지고 대부분 `OTHER`로 분류됩니다.

| `OTHER` 분류 건수 | 이벤트 분리 전 | 이벤트 분리 후 |
| --- | ---: | ---: |
| train | 17,686 | 0 |
| test | 56,967 | 2 |

따라서 공백은 제거 대상이 아니라 **변이 이벤트 구분자**로 처리해야 합니다.

## 확정한 전처리 규칙

1. `WT`와 변이는 구분하고, `WT`는 long 형식에서 제외합니다.
2. 실제 결측은 `WT`로 바꾸지 않고 `MISSING` 상태로 보존합니다.
3. 한 셀의 문자열을 공백 기준으로 분리하여 변이 이벤트별 행으로 변환합니다.
4. `raw_cell`과 `raw_variant`를 남겨 원문을 추적할 수 있게 합니다.
5. 모델 입력용 `normalized_variant`만 정규화합니다.
6. 현재 데이터에는 `p.`가 없지만 향후 입력에 대비해 제거 규칙을 지원합니다.
7. 각 이벤트에서 변이 유형, 위치와 위치 구간을 별도로 추출합니다.
8. 해석되지 않는 변이는 삭제하지 않고 `OTHER`로 보존합니다.

## 이벤트 분리 후 변이 유형

| 유형 | train | test |
| --- | ---: | ---: |
| 치환 `SUB` | 231,796 | 305,423 |
| 프레임시프트 `FS` | 9,914 | 25,877 |
| 종결 `STOP` | 13,451 | 1,985 |
| 결실 `DEL` | 3 | 2,583 |
| 삽입 `INS` | 0 | 1,097 |
| 결실·삽입 `DELINS` | 0 | 545 |
| 기타 `OTHER` | 0 | 2 |

train에는 거의 없거나 없는 `DEL`, `INS`, `DELINS`가 test에는 존재합니다.
따라서 test에서 처음 등장한 변이 유형을 오류로 삭제하지 않고, 학습에서
알 수 없는 범주로 안전하게 처리해야 합니다.
