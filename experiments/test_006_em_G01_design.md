# em_G01 저빈도·중복·고상관 처리 설계

## 처리 순서

```text
EMV46
→ 상수 피처 제거
→ 최소 활성 빈도 필터
→ 완전히 동일한 피처 제거
→ |Pearson correlation| ≥ 0.90 후보 그룹 탐색
→ 통합 우선순위로 대표 피처 유지
```

최소 활성 빈도 후보 `1, 2, 3, 5, 10, 20`은 각 outer 학습 fold 안에서
3-fold Macro F1으로 비교한다. 평균 점수가 같으면 fold 표준편차가 더 낮은
후보를 선택하며 validation/test 통계는 사용하지 않는다.

## 고상관 대표 피처 우선순위

1. 학습 fold에서 계산한 다중클래스 ANOVA F-score가 높은 피처
2. 5개 stratified fold에서 상위 20%에 안정적으로 선택된 피처
3. 0이 아닌 활성 값의 표본 수가 많은 피처
4. 제공 컬럼명에서 gene/hotspot/consequence/burden으로 해석 가능한 피처
5. 원본 유전자 컬럼의 결측률이 낮은 피처

4번은 외부 임상 데이터나 주석을 사용하지 않는 이름 기반 proxy다. 위 기준은
완전 중복 및 고상관 그룹 내부의 대표를 고르는 데만 사용하여 독립적인 희귀
암종 신호를 전역적으로 과도하게 삭제하지 않는다.

상관 계산량은 과적합과 실행시간을 제한하기 위해 통합 우선순위 상위 최대
3,000개에 대해 256개 block 단위로 계산한다. 선택 열과 모든 통계는 fit된
학습 fold에서 고정되고 validation/test에는 transform만 적용한다.

GBMLGG, KIPAN, STES 레이블은 분해하지 않으며 외부 데이터는 사용하지 않는다.
현재는 구현과 정적 검증만 대상으로 하고 학습·평가·submission 생성은 하지 않는다.
