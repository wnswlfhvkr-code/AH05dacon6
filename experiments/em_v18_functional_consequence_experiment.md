# em_v18 동의·기능 변이 분리 실험 결과

## 1. 문제 정의와 처리 원칙

`train.csv`의 단백질 변이를 모두 `mutated=1`로 바꾸면 단백질 서열을 바꾸지
않는 동의 변이와 기능 영향이 예상되는 변이가 같은 신호가 된다. `em_v18`은
동의 변이를 삭제하지 않고 다음처럼 역할을 분리한다.

- 유전자 값: `WT=0`, `synonymous=1`, `missense=2`, `in-frame/complex=3`,
  `nonsense/stop-gain=4`, `frameshift=5`
- 유전자 선택: 동의 변이를 제외한 기능 변이 환자 수 기준
- 암종 signature: 기능 변이 존재 여부만 사용하고 inner-fold OOF로 생성
- hotspot: 동의 변이를 제외한 반복 기능 변이 토큰만 사용
- 표본 집계: 결과별 log-count·비율, 기능 변이 비율, 복수 변이 유전자 수
- 같은 표본·유전자에서 반복된 동일 토큰은 한 번만 집계

## 2. 원시 변이 토큰 분석

`ID`, `SUBCLASS`를 제외한 4,384개 유전자 열과 6,201개 표본을 분석했다.

| missense | 164,740 | 161,051 | 64.56% |
| in-frame/complex | 176 | 171 | 0.07% |
| nonsense/stop-gain | 13,451 | 13,231 | 5.27% |
| frameshift | 9,914 | 9,767 | 3.89% |
| 합계 | 255,164 | 249,064 | 100.00% |

| 추가 관찰 | 값 |
| --- | ---: |
| 제거된 셀 내부 중복 토큰 | 6,100 |
| 서로 다른 토큰이 2개 이상인 표본·유전자 셀 | 20,041 |
| 동의 변이만 있는 표본·유전자 셀 | 52,896 |
| 기능 변이가 하나 이상 있는 표본·유전자 셀 | 165,997 |

동의 변이만 있는 52,896개 셀을 기능 변이와 같은 이진값으로 처리하지 않는 것이
핵심이다. hotspot은 결과 유형과 별개인 반복 위치 신호이며, 복수 변이는 희귀한
유전자 조합을 대량 생성하지 않고 표본 수준 집계로 압축했다.

## 3. 실험 설정

- 파이프라인: `em_v18`
- 설정: `configs/test_008.yaml`
- 평가: StratifiedKFold 5-fold OOF
- 보조 평가: 동일 시드의 80% 학습/20% 검증
- 과적합 기준: `80% 학습 Macro F1 - 20% 검증 Macro F1 > 0.1`
- 비교 기준: 동일한 E1 XGBoost 조건의 `em_v16`

```yaml
model:
  n_estimators: 100
  learning_rate: 0.1
  max_depth: 3
  min_child_weight: 5.0
  subsample: 0.8
  colsample_bytree: 0.8
  reg_alpha: 0.1
  reg_lambda: 5.0

preprocessing:
  name: em_v18
  min_functional_mutation_count: 5
  top_genes_per_class: 20
  min_hotspot_count: 5
  max_hotspots: 384
  inner_signature_folds: 5
```

fold 2만 0.40 아래이며 나머지 네 fold는 0.411 이상이다. 표준편차가 낮아

## 6. 동일 모델 조건 비교

| 파이프라인 | 전체 OOF F1 | fold 표준편차 | 80% 학습 F1 | 20% 검증 F1 | 과적합 격차 |
| --- | ---: | ---: | ---: | ---: | ---: |
| em_v16 E1 | 0.393177 | 0.008966 | 0.529101 | **0.418222** | **0.110879** |
| em_v18 | **0.411503** | **0.006874** | **0.549607** | 0.404442 | 0.145165 |
| 변화 | +0.018326 | -0.002092 | +0.020506 | -0.013780 | +0.034286 |

동의 변이를 기능 학습 신호에서 분리하자 전체 OOF와 fold 안정성은 개선됐다.
반면 고정 20% 검증 점수는 낮아지고 과적합 격차는 커졌다. 따라서 일반화 성능이
확정적으로 향상됐다고 단정하지 않고, OOF 개선과 단일 holdout 저하가 함께 있는
결과로 해석한다.

## 7. 판단과 후속 개선

1. OOF가 동일 조건의 E1보다 0.018326 높으므로 동의/기능 분리는 유지할 가치가 있다.
2. 과적합 격차 0.145165는 기준을 넘으므로 현재 설정을 최종 확정하지 않는다.
3. 선택 유전자가 4,102개로 많다. 기능 변이 최소 지지도 5/8/10을 fold 안에서
   비교해야 한다.
4. 유전자별 결과 one-hot은 피처 수가 급증하므로 안정 유전자에만 제한하는 것이
   안전하다.
5. 모든 fold가 100개 트리를 사용했다. 낮은 학습률과 조기 종료를 적용한 E4형
   실험은 별도 조건으로 비교해야 한다.

## 8. 생식세포 변이 해석 제한

이 데이터의 `TP53`, `BRCA1`, `BRCA2`, `VHL` 변이는 암종 분류용 종양 변이
신호로만 사용한다. 정상 대조 시료, variant allele fraction, zygosity, germline
확인 검사, 가족력과 임상 검증 정보가 없으므로 Li-Fraumeni, 유전성 유방·난소암,
VHL syndrome 또는 환자·가족의 생식세포 보인자 여부를 판단하지 않는다.

따라서 유전성 증후군 플래그, germline 추정값, 가족 위험도 피처는 `em_v18`에
포함하지 않았다.

## 10. 결론

- 동의 변이와 기능 변이를 동일한 `mutated=1`로 처리하는 문제를 제거했다.
- 전체 OOF F1은 0.411503으로 동일 모델 조건의 기존 E1보다 0.018326 높다.
- fold 변동성은 감소했지만 과적합 격차는 0.145165로 증가했다.
- `em_v18`은 유망한 후보이나 leaderboard 일반화를 보장하는 최종 파이프라인은 아니다.
- 종양 변이로부터 생식세포 변이나 유전성 암 증후군을 추론하지 않는다.
