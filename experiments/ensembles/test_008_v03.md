# test_008_v03 — E10: E8 LinearSVC + E9 LightGBM logit 앙상블

## 목적

E8의 고차원 희소 TF-IDF LinearSVC decision score와 E9의 TF-IDF·SVD128·F1
LightGBM 확률을 logit 공간에서 결합했다. 두 모델의 temperature와 E9
가중치는 평가 Fold를 제외한 환자에서만 선택했다.

## 검증과 결과

- 검증: 고정 SGKF 3-Fold × seeds `42, 2026, 777`
- E8 OOF Macro F1: `0.454945`
- E9 OOF Macro F1: `0.402767`
- E10 OOF Macro F1: `0.485415 ± 0.009638`
- E10 - E8: `+0.030471`
- E10 - E8A 참고: `+0.018141`
- Paired bootstrap 평균 변화: `+0.030388`
- 95% CI: `[+0.024319, +0.036379]`
- `P(변화 > 0) = 1.0000`
- Test 예측 변화율(E8 대비): `0.153181`
- 예측 0개 암종: 없음

## 판단

3개 seed에서 개선이 재현되었고 bootstrap 신뢰구간도 완전히 양수이므로
E10을 채택했다. 후속 E10B 실험의 기준 앙상블로 사용한다.

## GitHub 로컬 재현

`src.ensembles.train_jh_e10`을 현재 저장소의 `test_002_v09`, `test_002_v10`
출력에 적용한 결과다.

- E8 OOF Macro F1: `0.446917`
- E9 OOF Macro F1: `0.397811`
- E10 OOF Macro F1: `0.480721 ± 0.004865`
- E10 - E8: `+0.033804`
- 3개 seed 모두 개선
- Paired bootstrap 평균 변화: `+0.033636`
- 95% CI: `[+0.026821, +0.040335]`
- `P(변화 > 0) = 1.0000`
- 판정: 로컬 재현에서도 채택 기준 통과

Kaggle 원 실험과 GitHub 재현의 절대점수 차이는 E8·E9 상위 모델의
재학습 결과가 다르기 때문이다. 결합 후 개선 방향과 bootstrap 결론은
동일하게 재현되었다.

기존 E9 결과에 Fold별 Test 확률이 없어 로컬 Test 예측은
`test_probability_mean.npy`를 9개 seed·fold에 공통 적용했다. OOF 검증과
파라미터 선택에는 영향이 없다.

## 필요 입력

- E8: `oof_decision_by_seed.npy`, `test_decision_mean.npy`
- E9: `oof_probability_by_seed.npy`, `test_probability_by_seed_fold.npy`
- 고정 SGKF: `fixed_stratified_group_cv_splits.csv`

E9의 Fold별 Test 확률은 공용 `src.train_sgkf` 실행 시 자동 저장된다.
기존 E9 실행 결과에 Fold별 파일이 없으면 `test_probability_mean.npy`를
9개 seed·fold에 공통 적용하는 호환 모드로 실행하고, 사용한 방식을 요약
JSON의 `e9_test_probability_source`에 기록한다.

## 재현 명령

```bash
python -m src.ensembles.train_jh_e10 \
  --config configs/ensembles/test_008_v03.yaml
```
