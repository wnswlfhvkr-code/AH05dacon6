# test_008_v04 — E10A: E10 + EM16·EM24 pair expert

## 목적

E10의 26개 암종 예측을 유지하면서 반복적으로 혼동되는
`KIRC–KIPAN`, `LGG–GBMLGG` 쌍에만 EM16·EM24 혼합 pair expert를 적용했다.
평가 Fold를 제외한 환자에서 EM16 혼합 비율, temperature, pair 가중치를
선택했다.

## 검증과 결과

- 검증: 고정 SGKF 3-Fold × seeds `42, 2026, 777`
- E10 OOF Macro F1: `0.485415 ± 0.009638`
- E10A OOF Macro F1: `0.486569 ± 0.009325`
- E10A - E10: `+0.001154`
- Paired bootstrap 평균 변화: `+0.001144`
- 95% CI: `[-0.000328, +0.002669]`
- `P(변화 > 0) = 0.9393`

## 판단

평균 OOF는 소폭 상승했지만 bootstrap 95% CI가 0을 포함했다.
개선 크기가 작고 통계적 안정성이 부족하며, EM 계열의 Public 분포 이동
위험도 이미 확인되었으므로 최종 앙상블에서 제외했다.

**최종 판정: 미채택·폐기.**

## 필요 입력

- E10: `oof_probabilities_by_seed.npy`, `test_probability_mean.npy`
- EM16 aligned: `em16_sgkf_oof_probability_by_seed.npy`,
  `em16_sgkf_test_probability_by_seed_fold.npy`
- EM24 aligned: `em24_sgkf_oof_probability_by_seed.npy`,
  `em24_sgkf_test_probability_by_seed_fold.npy`

EM16·EM24 학습은 이 실행기의 범위가 아니며, 이 실행기는 저장된 aligned
OOF·Test 확률을 결합하는 재현 단위다.

## 재현 명령

```bash
python -m src.ensembles.train_jh_e10a \
  --config configs/ensembles/test_008_v04.yaml
```
