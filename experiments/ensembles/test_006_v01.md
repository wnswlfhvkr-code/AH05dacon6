# test_006_v01 — E8B: E8A + EM16 5-Fold 확률 앙상블

## 목적

E8A에 EM v16 class-aware signature·hotspot XGBoost 확률을 소가중치로 추가했다. EM16의 temperature와 weight는 평가 Fold를 제외한 환자에서만 선택했다.

## 검증과 결과

- E8A: 고정 SGKF 3-Fold × seeds `42, 2026, 777`
- EM16: 일반 StratifiedKFold 5-Fold OOF, seed 42
- E8A OOF: `0.467274 ± 0.006753`
- EM16 OOF: `0.388404`
- E8B OOF: `0.475723 ± 0.011464`
- E8B - E8A: `+0.008449`
- Bootstrap: `+0.008371`, 95% CI `[+0.002863, +0.013834]`
- Test 예측 변화율: `0.113904`

## 판단

내부 검증에서는 채택 기준을 통과했다. 다만 E8A와 EM16의 외부 OOF 분할이 서로 다르므로 E8C에서 동일 SGKF 재검증을 수행했다. 후속 Public 결과에서 EM 계열의 분포 이동 위험이 확인되어 최종 전략에서는 제외했다.

## 입력 파일

E8A 입력 파일 외에 EM16 일반 5-Fold에서 생성한 다음 배열이 필요하다.

- `em16_oof_probability.npy`: `(6201, 26)`
- `em16_test_probability_mean.npy`: `(2546, 26)`

## 재현 명령

```bash
python -m src.ensembles.train_jh_e8b \
  --config configs/ensembles/test_006_v01.yaml
```
