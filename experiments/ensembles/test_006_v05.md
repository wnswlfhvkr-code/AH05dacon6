# test_006_v05 — E10B-1: E10 + ID 제외 Word·Char TF-IDF

## 목적

E10에 원본 변이 문자열의 Word·Char TF-IDF Balanced LinearSVC 신호를
cross-fit으로 결합했다. 환자 ID가 문서 피처에 포함되지 않도록 유전자
4,384개 열만 사용했다.

## 검증과 결과

- 검증: 고정 SGKF 3-Fold × seeds `42, 2026, 777`
- TF-IDF 단독 OOF Macro F1: `0.428904`
- E10 seed별 OOF 평균: `0.485415`
- E10B-1 seed별 OOF: `0.488871 ± 0.010946`
- seed별 평균 변화: `+0.003455`
- 실제 제출 방식의 3-seed 확률 평균 OOF: `0.503848`
- 동일 확률 평균 기준 E10 OOF: `0.496327`
- 확률 평균 OOF 변화: `+0.007521`
- Paired bootstrap 평균 변화: `+0.007607`
- 95% CI: `[+0.002063, +0.013456]`
- `P(변화 > 0) = 0.9973`
- Test 예측 변화율: `0.032600`

## 점수 해석

`0.488871 ± 0.010946`은 각 seed 예측의 Macro F1 평균이다.
`0.503848`은 실제 제출처럼 3개 seed의 확률을 평균한 뒤 한 번 예측한
대표 OOF다. Bootstrap과 최종 채택 판정은 후자를 기준으로 했다.

## 판단

ID를 완전히 제외한 상태에서 개선되었고 bootstrap 95% CI도 완전히
양수이므로 E10B-1을 채택했다.

## 필요 입력

- E10: `oof_probabilities_by_seed.npy`, `test_probability_mean.npy`
- ID 제외 TF-IDF LinearSVC: `jsj_oof_decision_by_seed.npy`,
  `jsj_test_decision_by_seed_fold.npy`

TF-IDF LinearSVC 학습 출력은 `data/processed/test_006_v05_tfidf`에 둔다.
앙상블 실행기는 저장된 decision score를 결합한다.

## 재현 명령

```bash
python -m src.ensembles.train_jh_e10b1 \
  --config configs/ensembles/test_006_v05.yaml
```
